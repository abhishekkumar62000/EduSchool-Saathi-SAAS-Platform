# EduSchool-Saathi Marketing Website

## Goal
Build a polished, frontend-only SaaS website that clearly explains EduSchool-Saathi, showcases its school-management modules, and drives demo requests from school owners across Bihar.

## What I’ll build
- A sticky responsive navigation bar with smooth section links and a mobile menu.
- A high-impact opening section with clear positioning, calls to action, trust cues, and a realistic school dashboard preview.
- Dedicated sections for school-management pain points, platform overview, multi-school isolation, detailed modules, user roles, onboarding steps, benefits, rural and semi-urban mission, values, pricing, privacy, product dashboards, mobile experiences, FAQ, contact, and footer.
- Interactive role tabs that switch between tailored dashboard previews for super admin, school admin, teacher, student, and parent.
- Filterable feature modules, animated FAQ accordions, scroll reveals, responsive counters, and subtle interaction polish.
- A frontend-only demo request form with validation and a success confirmation; no data will be sent or stored.
- Responsive layouts for desktop, tablet, and 360–390px mobile widths with no horizontal overflow.

## Visual direction
- Premium Indian EdTech SaaS aesthetic using deep navy, crisp blue, warm coral, fresh green, and restrained neutral surfaces.
- Confident display typography, clear body copy, subtle borders and shadows, compact dashboard UI, and aspirational education imagery.
- No testimonials, invented customer logos, fake certifications, unsupported security claims, or fake contact information.

## Technical details
- Build the site as reusable React sections and UI components within the existing TanStack Start application.
- Define all color, typography, radius, shadow, and animation choices as semantic Tailwind v4 design tokens.
- Use Lucide icons, accessible controls, semantic landmarks, focus states, reduced-motion handling, and keyboard-friendly modal/accordion behavior.
- Keep every product statistic and dashboard row clearly presented as mock/demo content.
- Add route-specific SEO metadata for the home page.
- Verify compilation, desktop/mobile rendering, navigation, role switching, feature filtering, FAQ behavior, and the demo form flow.

## Scope boundaries
- Frontend presentation only.
- No backend, database, authentication, payment processing, external APIs, WhatsApp/SMS integration, or real school records.
